# AI 시티: 공존의 선택

중학생을 위한 1인용 카드 게임. 이벤트 카드를 공개하고 도시의 문제에 대응하며, AI와 인간이 함께 살아가는 도시를 키워 보세요. 주사위 없이 섞인 이벤트 카드 순서로 매번 다른 상황이 펼쳐집니다.

## 기획

### 목표
8장의 이벤트를 해결한 뒤 도시의 네 지표를 모두 안전하게 유지합니다. 한 지표가 0이 되면 즉시 게임 오버입니다. AI를 많이 쓰는 것이 언제나 정답은 아니며, 성장과 시민의 삶·안전·공정성 사이에서 균형을 찾는 것이 목표입니다.

### 지표
- **도시 성장** — 일자리, 경제, 기반시설
- **시민 행복** — 생활의 질, 돌봄, 신뢰
- **AI 안전** — AI의 신뢰성, 안전, 오류 대응
- **공정성** — 혜택과 부담이 시민에게 공평하게 돌아가는 정도

각 지표는 0~10입니다. 시작값은 성장 5, 행복 5, AI 안전 5, 공정성 5입니다. 선택 결과는 카드에 명시하며 임의 판정은 없습니다. 지표는 0~10 범위를 넘지 않습니다.

### 한 판의 흐름
1. 이벤트 덱을 섞고 한 장을 공개합니다.
2. 상황을 읽고 선택지 하나를 고릅니다.
3. 결과에 적힌 지표 변화를 적용합니다.
4. 8개 이벤트를 해결하면 최종 도시와 시민·AI 공동 선언문을 확인하고, 함께 발표합니다.

### 성공/실패
- 지표 중 하나라도 0이 되면 즉시 게임 오버
- 8개 이벤트를 마치고 모든 지표가 3 이상이면 공존 성공
- 그 외에는 도시가 살아남았지만 균형을 더 살펴야 하는 결말

### 이벤트 주제
AI 일자리, 학교·교육, 의료·돌봄, 개인정보, 편향, 가짜뉴스, 교통·환경, 정전·오류, 지역 상권, 시민 참여 등 다양한 관점을 다룹니다. 선택에는 이득과 비용이 함께 있고, 특정 역할이나 답을 정답으로 강요하지 않습니다.

### 화면 디자인
도시를 배경으로 한 그림책풍 장면을 사용합니다. 정장을 입은 AI 시청 비서가 상황을 말풍선으로 설명하고, 플레이어는 화면 아래의 선택 카드 중 하나를 고릅니다. 라운드가 진행되며 가장 낮은 지표에 따라 도시 레벨과 배경 분위기가 달라집니다. 손실 없이 서로 다른 지표 2개 이상을 올리는 선택을 하면 협력 배지를 얻고, 마지막에 배지 수에 맞는 칭호를 받습니다.

## 개발 순서
1. **기획 고정:** 1인용, 카드 기반, 주사위 없음, 4개 지표, 8라운드의 규칙을 먼저 문서화한다.
2. **핵심 플레이 구현:** 이벤트 덱 섞기, 선택지 표시, 지표 적용, 라운드 진행, 게임 종료를 만든다.
3. **콘텐츠 추가:** 중학생이 이해하기 쉬운 표현으로 다양한 도시 이벤트와 결과를 작성한다.
4. **접근성·화면 구성:** 도시 배경과 AI 안내 캐릭터를 배치하고, 모바일에서도 큰 글자와 선택 카드를 읽기 쉽게 만든다.
5. **검증·배포:** 새 게임, 선택 결과, 지표 경계, 승리·실패 흐름을 확인하고 GitHub Pages로 공개한다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 빌드 도구나 외부 라이브러리는 필요하지 않습니다.

## 기술
HTML, CSS, JavaScript만 사용하는 정적 웹 앱입니다. 게임은 브라우저 안에서 작동하며 서버나 계정이 필요 없습니다.
